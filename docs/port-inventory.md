# Port inventory (TypeScript → Python)

Every engine function, rule option, AI heuristic and test in the TypeScript app, and where it lives in Python. Parity fixtures were generated by running the TypeScript engine under Bun (see `decisions.md`, section 3), not written by hand.

## Rule options (all carried over; camelCase → snake_case)

`cols`, `boardStyle`, `extraMarks`, `soldiersPerSide`, `queens`, `queenStart`, `queenMarkIndex`, `diceCount`, `faces`, `blankValue`, `diceApplication`, `diceOrder`, `fixedOrder`, `rethrow` (`none`/`single`/`triple`), `startRule`, `track` (`loop`/`loop-from-middle`/`figure-eight`), `activation` (`step`/`up`/`first-middle`), `activationOrder`, `allowMiedut`, `capturesInactive`, `stacking`, `jumpOwnSoldiers`, `kingMode` (`recruit`/`push`), `kingMovement`, `royalsShareWithOwn`, `kingKnockOut`, `kingAcquire` (`landing`/`unjarga-first`/`unjarga-every`), `kingAloneLoses`, `royalVerticalCrossing`. The registry is compared against the TypeScript options for every variant by `tests/parity/test_parity.py::test_variant_registry_matches_fixture_options`.

## AI

| TypeScript (`ai/src`) | Python (`src/sahkku/ai`) |
| --- | --- |
| `evaluate` (material, awake soldiers, middle-row control, queen value, king ownership, threats) | `evaluate` (evaluate.py), same weights |
| Easy: random, captures ×4, re-throws ×0.4 | `_easy` |
| Medium: greedy one-ply on `evaluate` | `_medium` |
| Hard: expectimax, dice outcome multisets, beam 4/2, memo, node/time budget | `_hard`, `_Search` (+ cancel flag, per-node clock check) |
| `mulberry` seeded rand | `random.Random` |
| `scripts/selfplay.ts` | `python -m sahkku.ai.selfplay` (multi-process) |

## UI screens

Variant selector with credit lines and the Custom editor → `ui/dialogs.py`; board, dice tray, move log, rules panel, undo/restart, stakes counter → `ui/play.py`, `ui/board.py`, `ui/scene.py`, `ui/controller.py`; tutorial → `ui/tutorial.py`; About & credits → `ui/about.py`; first-run notice and settings → `ui/dialogs.py`; new: copy game record, thinking indicator with cancel, position as text.

## Not ported

Nothing was dropped. The TypeScript e2e scripts were replaced by the NiceGUI user-simulation test. Not ported by design: the Vite/React build, the Playwright config, and the Bun e2e runner.
